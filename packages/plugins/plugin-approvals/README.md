# @objectstack/plugin-approvals

The multi-step approval engine: the `sys_approval_process`, `sys_approval_request` and `sys_approval_action` objects and the `IApprovalService` that drives a record through its approval steps. `ApprovalsServicePlugin` registers both with the kernel.

```typescript
import { ApprovalsServicePlugin } from '@objectstack/plugin-approvals';
```

Documentation: [Approvals](https://objectstack.ai/docs/automation/approvals)
