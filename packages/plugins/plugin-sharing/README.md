# @objectstack/plugin-sharing

Record-level sharing: the `sys_record_share` object, the middleware that enforces an object's `sharingModel`, and the `ISharingService`. `SharingServicePlugin` registers them with the kernel.

```typescript
import { SharingServicePlugin } from '@objectstack/plugin-sharing';
```

Documentation: [Sharing service](https://objectstack.ai/docs/kernel/runtime-services/sharing-service)
