# @objectstack/connector-openapi

The OpenAPI connector generator: it turns a declarative OpenAPI 3.x document into connector actions on the automation engine's connector registry (ADR-0023), with a self-contained static-auth HTTP transport.

```typescript
import { ConnectorOpenApiPlugin } from '@objectstack/connector-openapi';
```

Documentation: [Connectors](https://objectstack.ai/docs/automation/connectors)
