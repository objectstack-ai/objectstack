# @objectstack/connector-slack

The Slack Web API connector: it registers `chat.postMessage`, `chat.update` and `call` actions on the automation engine's connector registry (ADR-0018 §Addendum, ADR-0022).

```typescript
import { ConnectorSlackPlugin } from '@objectstack/connector-slack';
```

Documentation: [Connectors](https://objectstack.ai/docs/automation/connectors)
