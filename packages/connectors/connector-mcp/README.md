# @objectstack/connector-mcp

The Model Context Protocol (MCP) connector: a generic adapter that turns the tools of any MCP server into connector actions on the automation engine's connector registry (ADR-0024), so a flow can call them like any other action.

```typescript
import { ConnectorMcpPlugin } from '@objectstack/connector-mcp';
```

Documentation: [Connectors](https://objectstack.ai/docs/automation/connectors)
