Studio field inspector: when a field of a read-only base package opens in display-patch mode, every control it locks (API name, Type, Required and Unique, Default value, option values and colours, Track history, the rule editors, Move up/down, Remove and the rest) now explains itself. The editable display properties (Label, Description, Help text, Placeholder, option labels) carry no reason.
