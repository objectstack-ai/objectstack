docs(spec): `actionLayout.record`'s description names the grid row menus it orders

Clause-②: no
Metadata-protocol: none

The `record` arm of an object's `actionLayout` already ordered a grid row's ⋮ menu and its right-click menu, but its description named only the record header (record page, side preview, a phone's bottom bar). The description now says so: in those row menus the actions `pinned` names come first, then those `more` names, then the rest as before, and which action a row draws as its button does not change. Description text only; the shape and what it accepts are unchanged.
