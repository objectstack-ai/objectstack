---
title: "Renderer types"
description: "The renderer types the ObjectUI component packages register, for apps that render their own JSON with the SDK"
---

<Callout type="warn" title="SDK only">
  These types exist only inside an app that renders JSON with the ObjectUI SDK. None of them is in
  `sdui.manifest.json`, so an ObjectStack page cannot use them. The components a page can hold are in the
  [component reference](/docs/ui/components).
</Callout>

Importing `@object-ui/components` registers these types with the [component registry](/docs/frontend/component-registry);
`view-switcher`, `filter-ui` and `sort-ui` register when `@object-ui/plugin-view` is imported. Each type's
inputs are declared in its `ComponentRegistry.register` call in the linked source file, and `@object-ui/types`
holds the schema types.
