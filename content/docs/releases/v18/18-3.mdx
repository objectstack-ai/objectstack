## Highlights — 18.3.0

- **An installed package is customized in its pair.** Each read-only base
  package has one paired `<base>.custom` package, and that pair is the only
  place an override of a base item (`d6e0967`, #28554) or a `__c` extension
  field (`447a2a6`, #28724) can be written (ADR-0146). The ensure door creates
  the pair when it is first needed (`0ecc2c4`, #28512), Studio customizes a
  read-only base's view, dashboard, report or flow into it (`d62d973`, #28711;
  `693e100`, #28824), and `GET /packages/:id/customizations` answers
  what a deployment changed on a base in one read (`519089e`, #28595). A write
  that names no package onto a packaged view, dashboard, report, translation
  or email template is refused (`bc02a77`, #28850), and
  `os migrate packageless-overlays` moves the rows Setup saved that way into
  the pair (`63acf35`, #28689).
- ⚠️ **A minor that breaks.** 305 of the 1,379 entries are declared breaking:
  117 graded `minor` because they narrow the metadata protocol, and 188 graded
  `patch` under the level rule. 264 of them need you to act; 41 are converted
  by `os migrate meta`. Read
  [the version number](#the-version-number-is-not-the-signal).
- **Ownership queues and assignment rules.** A record can wait in a queue
  until a member claims it, and assignment rules route new records
  (`a9f654e`, #26337, ADR-0142). `current_user.queues` is resolved by the
  platform (`e3470ed`, #27044).
- **Connectors carry each organization's credentials.** `oauth2` and
  `app-credential` join declarative connector-instance auth (`3238750`,
  #28213); an administrator connects an `authorization_code` instance for
  their organization (`e01edb2`, #28317), an OAuth-protected MCP server is
  dispatched with each organization's token (`7064615`, #28437), and `signed`
  auth arrives with three schemes (`b358e79`, #28273). An inline secret
  (`672bda0`, #28596) and a credential inside a connector URL (`1a8ba3f`,
  #29573; `cfd237f`, #29875) are refused where they are written.
- **One record page, opened in a drawer.** The record page is laid out again:
  frameless details, one timeline, related cards the reader arranges
  (`eef8373`, #27310), and a tab row under the header (`bf74607`, #28394). A
  record opened from a list opens in the drawer by default (`ea150b7`,
  #29108), and `navigation.mode` keeps `drawer`, `page`, `new_window` and
  `none` (`17b5152`, #26804). The page asks for everything it shows in one
  request (`0027c4a`, #27713).
- **A whole deployment exports as installable packages** in one read,
  `GET /packages/export` or `os package export` (`b3d1415`, #29755). A
  disabled package's export carries its items (`5afe7d7`, #29914), and a
  connector map the export withholds is named (`e756782`, #29746).
- **Amounts in the record's own currency.** `currencyMode: 'record'` points a
  currency field at a sibling ISO 4217 code field (`4145210`, #27268, ADR-0144),
  and nothing formats in US dollars by default any more (`79ed6f7`, #27249).
- **Plugins are bundled, and `os serve` loads them.** `bundled` is the one
  plugin packaging strategy (`fe9e856`, #27679), and `os serve` loads the
  plugins `os plugin install` installed, re-verifying each first (`d4ff1a0`,
  #27374).
- **Stored values get commands to bring them current.** `os migrate
  blank-single-values` (`5bd615e`, #29615), `os migrate option-codes`
  (`9b4fa6c`, #29700), `os migrate text-scalars` (`2545021`, #29776) and
  `os migrate audit-key-material` (`a5df094`, #26772) rewrite what older
  releases stored. See [after the boot](#4-after-the-boot).

## What's new in 18.3.0

### The version number is not the signal

Every package still versions in lockstep. The level of a release says whether
**the metadata protocol** moved, and nothing else:

| Kind of change | Level |
| :--- | :--- |
| Added to the metadata protocol: a new authorable key, accepted value or metadata type | `minor` |
| Narrowed or retired: a key removed or tombstoned, a value refused, a requirement tightened | `minor` |
| Semantic: the meaning or default of an authorable key changes | `minor` |
| Everything else: REST, drivers, services, the CLI, the Console, `feat:` and `fix!:` alike | `patch` |

So 18.3.0 carries 188 entries graded `patch` that say **BREAKING**, beside
117 graded `minor`. Of all 1,379, 238 are graded `minor` and 1,141 `patch`;
none is `major`. Pin exact versions of both scopes, and read the release
notes for every version you cross.

## Upgrade checklist

⚠️ For an 18.2.0 app. From 18.1.0, walk the
[18.2.0 checklist](/docs/releases/v18/18-2#upgrade-checklist) first, and so
on back to the [18.0.0 checklist](/docs/releases/v18/18-0#upgrade-checklist)
from 17.x.

### 18.3.0

<Callout type="warn">
**How far this list has been walked.** Not at all. It is compiled from the
changesets, and no app has been moved from 18.2.0 to 18.3.0 for this page.
Each step names the entry it comes from; read that entry for the exact
refusal.
</Callout>

#### 1. Move the pins

- **Move every `@objectstack/*` dependency, and every `@object-ui/*` one, to
  `18.3.0` together**, with `@objectstack/skills` and `create-objectstack`
  where you use them. Pin the exact version: a caret range takes every later
  18.x by itself, and a patch can break a non-protocol surface.
- **Drop `@object-ui/app-shell` and `@object-ui/plugin-ai`**, which do not
  publish 18.3.0 (`6a7c0fe`, `c59b1bf`).
- **Rebuild a plugin packaged `manifest-deps` as `bundled`**: `os plugin
  install` and `os plugin publish` refuse a stale `.osplugin` with the
  schema's prescription (`fe9e856`, `47c3e12`, `ed0e71d`).

#### 2. Run the build, and fix what it refuses

```bash
os validate
os build
os migrate meta --from 17     # the protocol-18 step, with this release's entries
```

Fix each refusal with its line in [需手动处理](#action-required) or
[自动迁移](#migrated-for-you). The ones an app is most likely to meet:

- an override of a base package's item, or a `__c` field, written anywhere
  but the base's `<base>.custom` pair (`d6e0967`, `447a2a6`);
- a record `navigation.mode` of `modal`, `split` or `popover` (`17b5152`),
  and a form view `type` of `split`, `drawer` or `modal` (`14e9685`);
- a list view's `options` bag (`8eeb3b3`), a record page's `slots.tabs`
  (`6dbff8e`), and an object's `titleFormat`, which takes the `nameField`
  prescription (`3557366`);
- a `${…}` token in an action's `description`, a param's `helpText` or an
  `outcomeMessages` entry (`7e3822c`);
- a `fixed` currency config with no code (`0cd578f`), and bare date
  subtraction in a formula (`51058ef`);
- a flow loop not closed by a `type: 'back'` edge, or a malformed loop,
  parallel or try_catch region (`5f7d554`, `0814b89`, `dd4a21f`);
- an app navigation `visible` that does not parse, and a page variable that is
  not unique, named and seeded (`256c86b`, `d9c4cdc`);
- an inline secret on a connector instance, a credential in a connector URL,
  or a key a connector entry does not declare (`672bda0`, `1a8ba3f`,
  `cfd237f`, `3e54f99`);
- a validation rule, `requiredWhen`, `readonlyWhen`, option `visibleWhen` or
  hook `condition` that orders a text or boolean field against a number
  (`4c2cd29`, in the code but not yet in the CHANGELOG): write `size(...)`, a
  number field, or a cast only when every value is numeric text.

#### 3. Before the first boot

- **Move each connector credential out of its metadata.** An inline secret on
  a connector instance is refused at the write door (`672bda0`); an
  administrator sets the credential in the environment's credential store,
  and a missing one degrades its instance instead of failing the boot
  (`7735d1d`). An `authorization_code` instance is connected per
  organization (`e01edb2`).
- **Give each organization a default currency** if a mail or in-app template
  formats a `currency` hole with no argument: with none, the render refuses
  it (`79ed6f7`).

#### 4. After the boot

- **Run `os migrate meta --stored`** to list and rewrite the stored rows the
  conversions touch.
- **Run `os migrate packageless-overlays`**, then with `--apply`, to move the
  customizations Setup saved without a package into each base's `.custom`
  pair (`63acf35`, `91f6a0b`, `a19759a`). Until a row is moved, a write that
  names no package onto it is refused (`bc02a77`, `838a802`).
- **Run the stored-value commands, a dry run first and then `--apply`**:
  [`os migrate audit-key-material`](/docs/deployment/cli#os-migrate-audit-key-material)
  (`a5df094`),
  [`os migrate blank-single-values`](/docs/deployment/cli#os-migrate-blank-single-values)
  (`5bd615e`),
  [`os migrate option-codes`](/docs/deployment/cli#os-migrate-option-codes)
  (`9b4fa6c`) and
  [`os migrate text-scalars`](/docs/deployment/cli#os-migrate-text-scalars)
  (`2545021`). A field switched to `currencyMode: 'record'` takes
  [`os migrate record-currency-codes`](/docs/deployment/cli#os-migrate-record-currency-codes)
  (`a3d24c9`).
- **Update API clients for the doors that now refuse what they used to
  ignore**: an unknown or bracketed query parameter on the package, draft,
  `/meta` and list doors (`e1ab32e`, `96e7a43`, `d659c1d`, `08610a9`,
  `186a83a`), an empty projection or search-field override (`4702c46`,
  `86f2afe`), and an unknown key on the datasource and analytics bodies
  (`819b101`, `fa5e863`). Each answers `400` naming what it refused.
- **Check who an approval, a sharing rule or a recipient reaches** past
  10,000 holders, and that a failed membership read now refuses instead of
  answering nobody (`2789ba7`, `9bdfe37`, `e0187d0`).
