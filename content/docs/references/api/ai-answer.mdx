The AI answer follow-up routes: saved questions, an answer turned into an
artifact, and an answer's rating.

| Method | Path | Request | `data` on success |
|:--|:--|:--|:--|
| GET    | `/api/v1/ai/saved-questions` | none | `ListAiSavedQuestionsResponseSchema` |
| POST   | `/api/v1/ai/saved-questions` | [`CreateAiSavedQuestionResponseSchema](CreateAiSavedQuestionRequestSchema`) (201) |
| DELETE | `/api/v1/ai/saved-questions/:id` | none | no body (204) |
| POST   | `/api/v1/ai/saved-questions/:id/run` | none | `RunAiSavedQuestionResponseSchema` |
| POST   | `/api/v1/ai/conversations/:id/turns/:turnId/artifact` | [`CreateAiAnswerArtifactResponseSchema](CreateAiAnswerArtifactRequestSchema`) (201) |
| GET    | `/api/v1/ai/conversations/:id/turns/:turnId/feedback` | none | `GetAiAnswerFeedbackResponseSchema` |
| POST   | `/api/v1/ai/conversations/:id/turns/:turnId/feedback` | [`SetAiAnswerFeedbackResponseSchema](SetAiAnswerFeedbackRequestSchema`) |
| DELETE | `/api/v1/ai/conversations/:id/turns/:turnId/feedback` | none | no body (204), also when no rating was there |

Like the other `/api/v1/ai/**` shapes in `protocol.zod.ts`, these describe
the wire, not a protocol this repo serves: the producer is the cloud AI
service (`service-ai`: `routes/saved-question-routes.ts`,
`routes/feedback-routes.ts`, `saved/saved-question-store.ts`,
`saved/source-artifact.ts`, `feedback/answer-feedback-store.ts`). Every
success body is the platform envelope `{ success: true, data }` and each
response schema here is the `data` payload; every failure body is
`{ success: false, error }` with `error` one of the three route errors below.

Every route is the signed-in caller's own: a saved question that is not the
caller's answers 404, and a conversation that is not the caller's answers 403
on the artifact and feedback routes.

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **object** | `string` | ✅ | The machine name of the object the figures were read from |
| **label** | `string` | optional | The object's plural label, or its label when it declares no plural. Translated only when the request is in Chinese and a `zh*` translation pack names the object; otherwise the authored label, not the caller's UI locale. Absent when the producer sets none: a reader falls back to `object` |
| **filter** | `any` | optional | The caller's `where`, in the `$` query dialect, exactly as the engine accepted it: machine names only, no field labels, date placeholders such as `{today}` as written. Absent when no condition applied |
| **scope** | `Enum<'visible_to_you' \| 'all_records'>` | ✅ | The row scope the figures cover, judged by the producer per call from `ISecurityService.getReadFilter(object, ctx)` for this caller and `object`, under the same context the read ran under. `visible_to_you`: a row restriction applied, so the figures cover only the records the caller may read. The organization wall is a row restriction: under the `isolated` and `group` tenancy postures `getReadFilter` answers an `organization_id` predicate on every object that carries the column, for every caller but a platform admin whose object's posture lets them cross the wall, so an organization owner there reads `visible_to_you`. `all_records`: stated only when that call RESOLVED to `undefined`, so no row restriction applied; for a caller no row rule or sharing narrows, that is the `single` posture, an object outside tenancy, a platform admin crossing the wall, or a system context. An absent security service, an absent `getReadFilter`, a call that throws or rejects, or a call made under any other context than the read's own states `visible_to_you`. A restriction applied is the fact stated, not a count of rows excluded. The value speaks for `object` only, not for the objects behind `related` lookup paths. Always present, one of these two values |
| **groupBy** | `string[]` | optional | The field names the figures were grouped by, in order |

| **orderBy** | `{ field: string; order?: Enum<'asc' \| 'desc'> }[]` | optional | The ordering applied, in order of precedence |
| **limit** | `integer` | optional | The row or group cut applied (a top-N read or a group cut). Present only together with `orderBy` |
| **related** | `string[]` | optional | The lookup paths read in the same call, dotted from the object (for example `client.relationship_manager`) |
| **latestPer** | `{ groupBy: string; orderField: string }` | optional | Present when the answer keeps only the latest row per group |
| **records** | `integer` | optional | How many records the figures cover — a count, never a list: the match total for a page read, the summed group counts for an aggregate or a chart, 1 for `get_record`. Absent when unknown, never guessed |
| **line** | `string` | ✅ | The finished one-line citation, in the request language. The producer keeps it to at most 280 characters; a reader does not refuse a longer one |
