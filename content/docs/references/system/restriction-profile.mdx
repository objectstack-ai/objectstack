## RestrictionProfile

What a target environment does not let metadata do, published by that environment; an absent profile means no restriction

### Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **allowCode** | `boolean` | ✅ | Whether metadata that carries code is allowed (object lifecycle hooks, named handler functions, code plugins) |
| **allowScheduledAutomation** | `boolean` | ✅ | Whether scheduled automation is allowed (flows of type 'schedule' and scheduled background jobs) |
