## RestrictionProfile

What a target environment does not let metadata do, published by that environment; an absent profile means no restriction

### Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **allowCode** | `boolean` | ✅ | Whether metadata that carries in-process code is allowed (handler-form hooks and jobs, named handler functions, code plugins, the script flow node); sandboxed JS bodies are governed by allowSandboxedJs |
| **allowSandboxedJs** | `boolean` | ✅ | Whether a sandboxed JavaScript body (language 'js') is allowed on hooks, actions and jobs; expression bodies are governed by neither this key nor allowCode |
| **allowScheduledAutomation** | `boolean` | ✅ | Whether scheduled automation is allowed (flows of type 'schedule' and scheduled background jobs) |
| **allowedFlowNodeTypes** | `Enum<'start' \| 'end' \| 'decision' \| 'assignment' \| 'loop' \| 'create_record' \| 'update_record' \| 'delete_record' \| 'get_record' \| 'http' \| 'notify' \| 'save_notice' \| 'script' \| 'screen' \| 'wait' \| 'subflow' \| 'map' \| 'connector_action' \| 'parallel_gateway' \| 'join_gateway' \| 'boundary_event' \| 'approval' \| 'approval_revise'>[]` | ✅ | Flow node types a flow may use (FlowNodeAction ids plus the spec-declared plugin node types approval and approval_revise); a type of that vocabulary not listed is forbidden |
| **versions** | `{ spec: string; skills: string }` | ✅ | The @objectstack/spec and @objectstack/skills versions the environment runs |
