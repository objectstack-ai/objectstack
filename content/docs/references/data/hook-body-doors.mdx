The two platform doors a sandboxed script body (a hook, action or job body)
reaches for records it may not write itself: mail goes through the mail
service, and a timeline entry goes through the activity door. A body asks for
each with its own capability token (`email.send`, `activity.append`,
`HookBodyCapability`), and calls it as `ctx.email.send(input)` /
`ctx.activity.append(input)`.

Each input below is what the BODY may say. What the platform says about the
message or the entry is stamped by the door and is not an input: the sender,
the user the mail is sent by, the organization it belongs to, the actor of a
timeline entry and the origin naming the body that wrote it. A key outside
the shape is refused, never dropped, so a body that names one of those is
told at the call.

## BodyActivityAppendInput

ctx.activity.append input: one entry a script body adds to a record timeline. metadata is at most 8000 characters as JSON.

### Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **object** | `string` | ✅ | Object name of the record the entry is about |
| **recordId** | `string` | ✅ | Id of the record the entry is about |
| **type** | `string` | ✅ | Activity kind, from the open vocabulary less the platform-only values |
| **summary** | `string` | ✅ | One-line summary |
| **recordLabel** | `string` | optional | Display label of the record, as of the entry |
| **source** | `{ object: string; id: string }` | optional | The record the entry points at for its detail |
| **metadata** | `Record<string, any>` | optional | Display hints stored beside the entry, at most 8000 characters as JSON |

## BodyMailSendInput

ctx.email.send input: a message a script body hands to the mail service. At most 50 recipients across to, cc and bcc together; each of to, cc and bcc at most 4000 characters as recorded ("Name" `<address>`, joined by ", "); a replyTo at most 320 characters as recorded.

### Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **to** | `string \| { name?: string; address: string } \| (string \| { name?: string; address: string })[]` | ✅ | Recipient address, or a list of them |
| **cc** | `string \| { name?: string; address: string } \| (string \| { name?: string; address: string })[]` | optional | Carbon-copy recipients |
| **bcc** | `string \| { name?: string; address: string } \| (string \| { name?: string; address: string })[]` | optional | Blind carbon-copy recipients |
| **replyTo** | `string \| { name?: string; address: string }` | optional | Reply-To address; the sender itself is the configured one |
| **subject** | `string` | ✅ | Subject line |
| **text** | `string` | optional | Plain-text body |
| **html** | `string` | optional | HTML body |
| **related** | `{ object: string; id: string }` | optional | The record the message is about |

### Nested Shape: `BodyMailSendInput.related`

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
