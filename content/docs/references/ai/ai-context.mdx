| **field** | `string` | optional | The child's reference field that points at the root. Required when the child has several such fields; with one, it may be omitted. Resolved once, on the published definition |
| **fields** | `string[]` | optional | The columns read for each row, in order (at most 10). A lookup among them is answered with the name of the record it points at. Omit to read the row's name only |
| **where** | `any` | optional | Which child rows the list carries: a filter on the child's own fields, in the object filter form. A bare value is `$eq`; the operators are $eq, $ne, $in, $nin, $gt, $gte, $lt, $lte, $null, $exists, joined by $and / $or nested at most 32 deep. Comparands are literal values: no dotted path, no field-to-field comparand, no $now anchor and no `{…}` placeholder. Joined to the link with $and and read as the caller, so it grants nothing |
| **orderBy** | `{ field: string; order?: Enum<'asc' \| 'desc'> }[]` | optional | The order of the rows: `{ field, order }[]` on the child's own fields, `order` `asc` (the default) or `desc`. Without it the rows come in the data engine's order. A field the child does not offer as a sort (it declares `sortable: false`, or is a formula) leaves the list out of every answer |
