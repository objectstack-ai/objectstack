## AiChatNavParams

Params of an `ai:chat` navigation entry: the copy the AI inquiry home page draws before the first question.

### Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **title** | `string` | optional | Welcome heading drawn above the question box (at most 60 characters). Absent: the page's default heading. |
| **subtitle** | `string` | optional | One or two lines under the heading saying what the reader can ask about (at most 200 characters). |
| **placeholder** | `string` | optional | Placeholder text inside the empty question box (at most 100 characters). |
| **suggestions** | `string[]` | optional | Suggested questions offered as one-click starters, 1 to 4 non-empty entries of at most 100 characters each, shown in this order. |
