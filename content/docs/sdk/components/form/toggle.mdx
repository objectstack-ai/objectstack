---
title: "Toggle"
description: "Two-state button for toggling options on and off"
---

The Toggle component is a button that can be toggled between on and off states, useful for settings and preferences.

## Basic Usage

**Simple Toggle**

```json
{
  "type": "toggle",
  "label": "Toggle"
}
```

## Variants

**Default**

```json
{
  "type": "toggle",
  "label": "Default",
  "variant": "default"
}
```

**Outline**

```json
{
  "type": "toggle",
  "label": "Outline",
  "variant": "outline"
}
```

## Sizes

**Toggle Sizes**

```json
{
  "type": "flex",
  "properties": {
    "gap": 2,
    "align": "center",
    "children": [
      {
        "type": "toggle",
        "label": "Small",
        "size": "sm"
      },
      {
        "type": "toggle",
        "label": "Default",
        "size": "default"
      },
      {
        "type": "toggle",
        "label": "Large",
        "size": "lg"
      }
    ]
  }
}
```

## States

**Pressed State**

```json
{
  "type": "toggle",
  "label": "Pressed",
  "pressed": true
}
```

**Disabled State**

```json
{
  "type": "toggle",
  "label": "Disabled",
  "disabled": true
}
```
