---
title: "Slider"
description: "Select a value from a range"
---

## Examples

**Basic Slider**

```json
{
  "type": "slider",
  "label": "Volume",
  "defaultValue": [
    50
  ]
}
```

## Schema

```ts
interface SliderSchema {
  type: 'slider';
  name?: string;
  label?: string;
  min?: number;
  max?: number;
  step?: number;
  defaultValue?: number | number[];
}
```
