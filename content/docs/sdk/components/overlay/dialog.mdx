## Examples

**Dialog Trigger**

```json
{
  "type": "dialog",
  "trigger": {
    "type": "button",
    "label": "Open Dialog"
  },
  "title": "Dialog Title",
  "description": "Dialog description",
  "content": [
    {
      "type": "text",
      "content": "Dialog content goes here"
    }
  ]
}
```

## Schema

```ts
import type { SchemaNode } from '@object-ui/types';

interface DialogSchema {
  type: 'dialog';
  trigger: SchemaNode | SchemaNode[];
  title?: string;
  description?: string;
  content?: SchemaNode | SchemaNode[];
  footer?: SchemaNode[];
}
```
