## Examples

**Basic Drawer**

```json
{
  "type": "drawer",
  "trigger": {
    "type": "button",
    "label": "Open Drawer"
  },
  "title": "Drawer Title",
  "content": [
    {
      "type": "text",
      "content": "Drawer content"
    }
  ]
}
```

## Schema

```ts
import type { SchemaNode } from '@object-ui/types';

interface DrawerSchema {
  type: 'drawer';
  trigger: SchemaNode | SchemaNode[];
  title?: string;
  content?: SchemaNode | SchemaNode[];
  side?: 'left' | 'right' | 'top' | 'bottom';
}
```
