---
title: "Kbd"
description: "Display keyboard shortcuts and hotkeys"
---

The Kbd component displays keyboard shortcuts in a styled format.

## Basic Usage

**Copy Shortcut**

```json
{
  "type": "kbd",
  "keys": [
    "Ctrl",
    "C"
  ]
}
```

## Multiple Key Combinations

**Command Palette**

```json
{
  "type": "kbd",
  "keys": [
    "Ctrl",
    "Shift",
    "P"
  ]
}
```

**Search**

```json
{
  "type": "kbd",
  "keys": [
    "Cmd",
    "K"
  ]
}
```

**Submit**

```json
{
  "type": "kbd",
  "keys": [
    "Alt",
    "Enter"
  ]
}
```

## Schema

```ts
interface KbdSchema {
  type: 'kbd';
  keys: string[];                 // Keyboard keys
  className?: string;
}
```
