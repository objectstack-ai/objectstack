---
title: "Statistic"
description: "Display key metrics and statistical values with trend indicators"
---

The Statistic component displays numerical data and key metrics with optional labels, descriptions, and trend indicators.

## Basic Usage

**Simple Statistic**

```json
{
  "type": "statistic",
  "label": "Total Revenue",
  "value": "$45,231.89"
}
```

## With Trend Indicators

**Positive Trend**

```json
{
  "type": "statistic",
  "label": "Active Users",
  "value": "12,543",
  "trend": "up",
  "description": "+12.5% from last month"
}
```

**Negative Trend**

```json
{
  "type": "statistic",
  "label": "Bounce Rate",
  "value": "24.8%",
  "trend": "down",
  "description": "-3.2% from last month"
}
```

**Neutral**

```json
{
  "type": "statistic",
  "label": "Conversion Rate",
  "value": "3.24%",
  "trend": "neutral",
  "description": "No change"
}
```

## With Descriptions

**With Description**

```json
{
  "type": "statistic",
  "label": "Total Sales",
  "value": "145,892",
  "description": "Across all products this quarter"
}
```

## Schema

```ts
interface StatisticSchema {
  type: 'statistic';
  
  // Content
  label?: string;                       // Label/title of the statistic
  value: string | number;               // Main value to display
  description?: string;                 // Additional description text
  icon?: string;                        // Optional icon name
  
  // Trend indicator
  trend?: 'up' | 'down' | 'neutral';   // Trend direction
  
  // Styling
  className?: string;                   // Tailwind CSS classes
  
  // Base properties
  id?: string;
  visible?: boolean | string | { dialect?: string; source: string };
  testId?: string;
}
```
