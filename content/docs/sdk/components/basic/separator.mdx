---
title: "Separator"
description: "Visual divider between content sections"
---

## Examples

**Horizontal**

```json
{
  "type": "stack",
  "gap": 4,
  "children": [
    {
      "type": "text",
      "content": "Content Above"
    },
    {
      "type": "separator"
    },
    {
      "type": "text",
      "content": "Content Below"
    }
  ]
}
```

**Vertical**

```json
{
  "type": "flex",
  "properties": {
    "gap": 4,
    "children": [
      {
        "type": "text",
        "content": "Left"
      },
      {
        "type": "separator",
        "orientation": "vertical"
      },
      {
        "type": "text",
        "content": "Right"
      }
    ]
  }
}
```

## Schema

```ts
interface SeparatorSchema {
  type: 'separator';
  orientation?: 'horizontal' | 'vertical';
  className?: string;
}
```
