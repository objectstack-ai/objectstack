---
title: "Renderer Reference"
description: "Renderer types registered by the Object UI component packages, one page per type"
---

Each page in this reference documents one renderer type: the `type` value you write in a JSON schema, the
props it reads, and example schemas. The types are registered by `@object-ui/components` and the other
component packages when they are imported, through the [component registry](/docs/sdk/guide/component-registry).

The page slug is the type name, so `dialog` is documented at `/docs/sdk/components/overlay/dialog`.

The components a metadata author can place in an ObjectStack page are listed in `sdui.manifest.json`; those
are documented with the rest of the page metadata under [Views & Apps](/docs/ui).

## Basic

- [Separator](/docs/sdk/components/basic/separator) (`separator`) — Visual divider between content sections
- [Button Group](/docs/sdk/components/basic/button-group) (`button-group`) — Group multiple buttons together with shared styling
- [Pagination](/docs/sdk/components/basic/pagination) (`pagination`) — Navigate through pages of content
- [Navigation Menu](/docs/sdk/components/basic/navigation-menu) (`navigation-menu`) — Accessible navigation menu with dropdown support
- [Sidebar](/docs/sdk/components/basic/sidebar) (`sidebar`) — An app-level sidebar region that works in any host
- [Div (Deprecated)](/docs/sdk/components/basic/div) (`div`) — Generic container element - use Shadcn components instead

## Form

- [Input](/docs/sdk/components/form/input) (`input`) — Basic text input field for user data entry
- [Textarea](/docs/sdk/components/form/textarea) (`textarea`) — Multi-line text input for longer content
- [Select](/docs/sdk/components/form/select) (`select`) — Dropdown selection from a list of options
- [Combobox](/docs/sdk/components/form/combobox) (`combobox`) — Searchable dropdown for selecting from a list of options
- [Checkbox](/docs/sdk/components/form/checkbox) (`checkbox`) — Toggle selection with checkboxes
- [Radio Group](/docs/sdk/components/form/radio-group) (`radio-group`) — A set of checkable buttons where only one can be selected at a time
- [Switch](/docs/sdk/components/form/switch) (`switch`) — Toggle switch for binary options
- [Slider](/docs/sdk/components/form/slider) (`slider`) — Select a value from a range
- [Date Picker](/docs/sdk/components/form/date-picker) (`date-picker`) — Input for selecting dates with a calendar popup
- [Input OTP](/docs/sdk/components/form/input-otp) (`input-otp`) — One-time password input with auto-focus
- [Command](/docs/sdk/components/form/command) (`command`) — Fast command menu with search and keyboard navigation
- [Form](/docs/sdk/components/form/form) (`form`) — Form container with validation and submission handling
- [Calendar](/docs/sdk/components/form/calendar) (`calendar`) — Date selection component with single, multiple, and range modes
- [File Upload](/docs/sdk/components/form/file-upload) (`file-upload`) — Modern file upload component with drag-and-drop support
- [Toggle](/docs/sdk/components/form/toggle) (`toggle`) — Two-state button for toggling options on and off

## Layout

- [Aspect Ratio](/docs/sdk/components/layout/aspect-ratio) (`aspect-ratio`) — Maintain a consistent width to height ratio
- [Page](/docs/sdk/components/layout/page) (`page`) — Full-page container with title, description, and content sections

## Data Display

- [List](/docs/sdk/components/data-display/list) (`list`) — Display a list of items
- [Breadcrumb](/docs/sdk/components/data-display/breadcrumb) (`breadcrumb`) — Display the current location within a navigational hierarchy
- [Kbd](/docs/sdk/components/data-display/kbd) (`kbd`) — Display keyboard shortcuts and hotkeys
- [Statistic](/docs/sdk/components/data-display/statistic) (`statistic`) — Display key metrics and statistical values with trend indicators
- [Tree View](/docs/sdk/components/data-display/tree-view) (`tree-view`) — Hierarchical tree structure for displaying nested data

## Feedback

- [Loading](/docs/sdk/components/feedback/loading) (`loading`) — Loading spinner to indicate processing
- [Progress](/docs/sdk/components/feedback/progress) (`progress`) — Progress bar to show completion status
- [Skeleton](/docs/sdk/components/feedback/skeleton) (`skeleton`) — Placeholder for loading content
- [Spinner](/docs/sdk/components/feedback/spinner) (`spinner`) — Loading spinner indicator
- [Empty](/docs/sdk/components/feedback/empty) (`empty`) — Empty state placeholder with optional action
- [Toast](/docs/sdk/components/feedback/toast) (`toast`) — Brief notification messages that appear temporarily
- [Sonner](/docs/sdk/components/feedback/sonner) (`sonner`) — Toast notifications using Sonner library

## Overlay

- [Dialog](/docs/sdk/components/overlay/dialog) (`dialog`) — Modal dialog overlay for focused interactions
- [Drawer](/docs/sdk/components/overlay/drawer) (`drawer`) — Sliding panel from edge of screen
- [Tooltip](/docs/sdk/components/overlay/tooltip) (`tooltip`) — Contextual information on hover
- [Popover](/docs/sdk/components/overlay/popover) (`popover`) — Floating content panel
- [Alert Dialog](/docs/sdk/components/overlay/alert-dialog) (`alert-dialog`) — A modal dialog that interrupts the user with important content and expects a response
- [Sheet](/docs/sdk/components/overlay/sheet) (`sheet`) — Slide-in panel from the edge of the screen
- [Hover Card](/docs/sdk/components/overlay/hover-card) (`hover-card`) — Display rich content in a popup when hovering over a trigger
- [Context Menu](/docs/sdk/components/overlay/context-menu) (`context-menu`) — Display a menu on right-click or long-press
- [Dropdown Menu](/docs/sdk/components/overlay/dropdown-menu) (`dropdown-menu`) — Display a menu of actions or options triggered by a button
- [Menubar](/docs/sdk/components/overlay/menubar) (`menubar`) — Horizontal menu bar with dropdown menus

- [Toggle Group](/docs/sdk/components/disclosure/toggle-group) (`toggle-group`) — A group of toggle buttons where one or more can be selected

- [Filter Builder](/docs/sdk/components/complex/filter-builder) (`filter-builder`) — Visual query builder for constructing complex filter conditions

- [Filter UI](/docs/sdk/components/complex/filter-ui) (`filter-ui`) — Build flexible filter panels for list and view toolbars
- [Sort UI](/docs/sdk/components/complex/sort-ui) (`sort-ui`) — Configure sorting with dropdowns or button toggles
