---
title: "Spinner"
description: "Loading spinner indicator"
---

The Spinner component displays a loading indicator.

## Basic Usage

**Default Spinner**

```json
{
  "type": "spinner"
}
```

## Sizes

**Small**

```json
{
  "type": "spinner",
  "size": "sm"
}
```

**Medium**

```json
{
  "type": "spinner",
  "size": "md"
}
```

**Large**

```json
{
  "type": "spinner",
  "size": "lg"
}
```

## Schema

```ts
interface SpinnerSchema {
  type: 'spinner';
  size?: 'sm' | 'md' | 'lg';
  className?: string;
}
```

## Examples

### In Button

**Loading Button**

```json
{
  "type": "button",
  "label": "Loading...",
  "disabled": true,
  "children": [
    {
      "type": "spinner",
      "size": "sm"
    },
    {
      "type": "text",
      "content": "Please wait"
    }
  ]
}
```

### Centered

**Centered Spinner**

```json
{
  "type": "flex",
  "properties": {
    "justify": "center",
    "align": "center",
    "children": [
      {
        "type": "spinner",
        "size": "lg"
      }
    ]
  },
  "className": "h-32"
}
```
