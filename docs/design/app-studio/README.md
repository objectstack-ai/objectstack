# App Studio redesign — mockups (#37424)

These are design mockups for epic #37424. They live on a temporary branch and are not meant to be merged. All names, counts, people and dates are sample data.

| File | Screen |
|---|---|
| `Main.png` | Object list, with only system-shipped items |
| `WithCustom.png` | Object list once items are modified or new; the Modified-at and Source columns appear |
| `AppMenu.png` | Package switcher open, with "New package" |
| `Overview.png` | Package overview: the Info tab, plus the Pending and Publish history tabs |

`source/` holds the design-canvas sources (`.dc.html`). They render only inside the design-canvas runtime; the PNGs are what to read.
