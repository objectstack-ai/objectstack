# Record page v4 · design notes (2026-10-29)

## n41

面板模型（2026-10-29，维护者建议 + 席位综合）：右栏是一叠同形面板（时间线、每个关联表、审批、附件）。标题行：折叠 ▾ 紧跟标题文字（同 Claude Code「环境 ▾」），点标题即折叠；计数靠右；悬停时右端浮出 ⠿ 抓手 + ＋ ⤢ ⋯（不悬停时左侧不留空位），整行可拖；没有 ⋯ 菜单：「隐藏」是悬停浮出的 ⊘ 图标，上移/下移走抓手聚焦后 ⌥↑/⌥↓ 的键盘路径。（维护者 2026-10-29 修订：悬停项放右端、▾ 紧跟标题、取消 ⋯）0 条面板折成一行「还有 N 个空关联」。脚部「已隐藏 N 张 · 显示 · 恢复默认顺序」。头部动作行右端只有一枚「右栏」图标开关（⌘⇧,），不再有「时间线 | 关联」文字分段。

## n42

时间线与层级（2026-10-29）：时间线默认是右栏最上面的面板（带紧凑输入框 + 最近 3 条 + 查看全部），面板标题行 ⊞ 升格为独立列；工作型对象（stage / option kinds / files）在三栏层默认升格。两栏层：右栏常驻、时间线折成面板，不再有「相关 N」栏开关。抽屉按自己的宽度套同一规则：≥760 两栏（详情 | 右栏面板），更窄才页签——今天 1123 px 的抽屉仍被强制页签，是缺口。

## n43

左栏「全部报表」（2026-10-29）：控制台对每个非 Studio 应用固定注入（objectui#13020），与应用自己的报表组重复、无报表的应用也挂着。方案 1+2：有报表组 → 「全部报表 →」并入组尾；无组但有成员可看的报表 → 底部一行；没报表 → 不画。不加元数据键。
