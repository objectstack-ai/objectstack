# Record page v4 · design notes (2026-10-29)

## n41

面板模型（2026-10-29，维护者建议 + 席位综合）：右栏是一叠同形面板（时间线、每个关联表、审批、附件）。标题行：折叠 ▾ 紧跟标题文字（同 Claude Code「环境 ▾」），点标题即折叠；计数靠右；悬停时右端浮出 ⠿ 抓手 + ＋ ⤢ ⋯（不悬停时左侧不留空位），整行可拖；⋯ 悬停才出现，里面只有「隐藏」（维护者 2026-10-29：「隐藏按钮放出来感觉还不如之前的更多下拉」）；上移/下移不进菜单（「有了拖动，为什么还需要上移 / 下移」）——键盘排序作为拖拽的无障碍替代放在 ⠿ 抓手上：Tab 聚焦后 ⌥↑/⌥↓，tooltip 写明。0 条面板折成一行「还有 N 个空关联」。脚部「已隐藏 N 张 · 显示 · 恢复默认顺序」。头部动作行右端只有一枚「右栏」图标开关（⌘⇧,），不再有「时间线 | 关联」文字分段。

## n42

时间线与层级（2026-10-29）：没有「时间线开关」——时间线始终是右栏一块面板，面板标题行 ⊞ 升格为独立列、列头 ⊟ 收回；右栏整体由头部右端一枚图标开关。crumb 行取消：‹ 返回进标题上方小字；整页不画 ↑↓（维护者 2026-10-29：整页无兄弟集、看不到列表），抽屉顶栏保留 ↑↓ 与 ↑/↓、j/k 键，下钻层只留键盘。时间线默认是右栏最上面的面板（带紧凑输入框 + 最近 3 条 + 查看全部），面板标题行 ⊞ 升格为独立列；工作型对象（stage / option kinds / files）在三栏层默认升格。两栏层：右栏常驻、时间线折成面板，不再有「相关 N」栏开关。抽屉按自己的宽度套同一规则：≥760 两栏（详情 | 右栏面板），更窄才页签——今天 1123 px 的抽屉仍被强制页签，是缺口。

## n43

左栏「全部报表」（2026-10-29）：控制台对每个非 Studio 应用固定注入（objectui#13020），与应用自己的报表组重复、无报表的应用也挂着。方案 1+2：有报表组 → 「全部报表 →」并入组尾；无组但有成员可看的报表 → 底部一行；没报表 → 不画。不加元数据键。

## n44

并入 #27524（维护者 2026-10-29）：⑩ 子表紧凑行首列跳过回指当前记录的 FK——产品页的「商机产品明细」六行全是产品名是零信息；取第一个非本关系字段的列（商机名），chip 取数量/金额/状态。⑪ 折叠「动态」卡只留一行输入框（聚焦展开）+ 最近 3 条 + 查看全部，无筛选 chip 无工具条。

## n45

放大态（2026-10-29，维护者问「子表放大之后是否建议全屏 modal 浮出」，裁定不做 modal）：⤢ 仍是原地放大（?related=，Esc / ‹ 返回），但放大态把头部压成一行「‹ 返回 · 记录名 · 子表名 · 计数 + 动作」，要点条与阶段路径收起，表格占满其余高度；抽屉里占满抽屉主体。理由：modal 已退役、抽屉里会 dialog 叠 dialog、正文表编辑需要头部合计随之刷新、URL 可寻址与返回不必重做。

## n46 · 抽屉 v4（RecordDrawerV4Peek / RecordDrawerV4Max）

抽屉 v4（2026-10-29，维护者三问：「drawer 已经很宽了，全屏之后更窄了」「抽屉盖住了列表合理吗」「抽屉 ⤢ 原地最大化 我觉得有必要」）：现状 size:'auto' 按字段数撑到 960/1200 并可拖到 95vw，1440 下比整页正文 1136 还宽，又有 80% 黑遮罩把列表盖死——两头好处都没拿到。改为：抽屉封顶 md 720（拖拽上限 60vw）、去遮罩、列表可读可点、点行换记录；⤢ 原地铺满（URL 不变、Esc/⤡ 还原、栈不动）；「在整页打开」只留列表行 ↗（#27031）与头部 ⋯；整页「收为抽屉」只对从 ↗ 进来的保留。#26679 的「⤢ 跳整页」就此退役。split 读者偏好不变。
