# 记录页 v3 · 设计说明（2026-10-28）

板：RecordPageV3（三栏默认 + 面板开关）、RecordPageV3NoTimeline（时间线关闭）、RecordPageRef（主数据两栏）、RecordDrawerV3（抽屉一层下）、RecordMobile（手机三屏）。

- 栏的显示 = 默认值 + 用户开关。默认按对象推导、不加新键：工作型对象（检测到阶段字段 ∨ enable.files ∨ 有以它为父的 master_detail 子表）时间线栏默认开，其余默认关。面包屑行右侧两个面板开关（☴ 时间线 · ⊞ 关联，像 Claude Code 顶部那组图标）随时切换，按用户 × 对象记在浏览器里（与「打开记录」偏好同一机制，不进元数据）。关掉的栏折成关联栏底部的「动态」卡 / 页签；抽屉与手机是页签档，不画开关。 快捷键：⌘⇧T 时间线、⌘⇧R 关联（与 Studio 的 ⌘. 同一族），⌘K 里也可搜「显示 / 隐藏时间线」。容器放不下时栏自动折成页签 / 卡，容器变宽后恢复用户的选择。

- HotCRM 默认落点（用户可改）：时间线默认开 = 线索、商机、工单、任务（阶段）+ 客户、联系人、合同、报价（files）；默认关 = 产品、价目表、价目表条目、报价明细、商机明细、营销活动、营销活动成员、事件、参与者、预测、知识文章、文章反馈。有了开关，营销活动这类边界对象不必再裁，用户自己开。

- 抽屉 v3 顶栏：根层左侧空；一层下显示 ← + 路径（祖先可点）；右侧 ↑ ↓（当前层兄弟）· ⤢（整页打开，仅图标）· ✕；不显示对象名与第几条。页签 详情 / 时间线 / 关联 /（审批）；工作型对象时间线排第二，主数据排最后。

- 手机端：记录永远整页（没有抽屉、分屏偏好不生效）；顶栏 ‹ 返回 + 标题 + ↑↓ + ⋯；头部头像 + 名称 + 芯片、要点 2 列最多 4 项、阶段条压扁；页签档就是手机档（详情 / 时间线 / 关联，主数据对象时间线排最后）；主动作 + 一个次动作 + ⋯ 固定在底部动作条；关联记录整页推入，路径行承接桌面抽屉的 ← 路径，‹ 返回停在来处页签。列表用卡片行（头像 + 名 + 一句副标题 + 一个状态芯片），视图当横滑芯片，筛选 / 排序芯片一行，搜索与显示在顶栏，新建是右下 FAB。

- v3 相对 v2 的四处变化：① 详情分区去卡片边框，标题 + 细线 + 字段栅格，每段按字段数 1–3 列，空字段折叠、全空分区并成一行；② 时间线合成一条流（讨论 + 活动 + 字段变更），系统变更压成一行灰字，顶部分段过滤，评论框常驻顶部；③ 关联栏紧凑卡：标题 + 计数 + ＋，每行名称 + 一个芯片，最多 3 行，「查看全部 N 条 →」；审批/附件在栏底；④ 头部 1 主 + 2 次 + ⋯（刷新收进 ⋯），要点 6 项等宽，面包屑行右侧只有 ↑↓，不显示第几条。栏宽 1 : 1 : 320。

- 输入全部来自对象语义角色（ADR-0085）：nameField / imageField / highlightFields / stageField(+kind) / fieldGroups / enable.feeds·activities·trackHistory / 关系字段 relatedList·Title·Columns·Filter；排序继承子对象默认列表视图。没有新的布局键：三栏/两栏/页签由记录视图宽度决定，抽屉里同一张页按页签档画。
