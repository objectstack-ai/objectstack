# ObjectUI Roadmap

This file is a pointer. Plans and their status live where they are tracked, so they cannot go
stale here.

ObjectUI is the `ui/` workspace of the ObjectStack repository. Its work is planned and tracked
in that repository:

- **Open work:** [issues](https://github.com/objectstack-ai/objectstack/issues). Filter by the
  `area:*` labels for one feature axis and by `priority:*` for order.
- **Release targets:** [milestones](https://github.com/objectstack-ai/objectstack/milestones) and
  the `target:*` labels.
- **Platform roadmap:** the repository [ROADMAP.md](https://github.com/objectstack-ai/objectstack/blob/main/ROADMAP.md) and
  [NORTH-STAR.md](https://github.com/objectstack-ai/objectstack/blob/main/docs/NORTH-STAR.md).
- **What has shipped:** [CHANGELOG.md](./CHANGELOG.md) and the per-package `CHANGELOG.md` files.
- **Design decisions:** the ADRs in [docs/adr](./docs/adr). ADR numbers are allocated in the
  ObjectStack repository's [docs/adr](https://github.com/objectstack-ai/objectstack/tree/main/docs/adr).

The long-form roadmap this file used to hold stopped at v3.3.2 (May 2026). It is in the git
history of this path.
