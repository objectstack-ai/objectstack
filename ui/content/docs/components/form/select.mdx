## Schema

```ts
interface SelectSchema {
  type: 'select';
  name?: string;
  label?: string;
  options: { label: string; value: string | number }[];
  placeholder?: string;
  required?: boolean;
  disabled?: boolean | string | { dialect?: string; source: string };   // boolean, predicate expression, or CEL envelope
  wrapperClass?: string;
}
```

<Callout type="warn">
  `wrapperClass` is now typed. The renderer has read it all along — it lands on the
  wrapper element around the select and its label — but it went undeclared until
  objectui#7722, surviving on what was then `BaseSchema`'s index signature (objectui#8347 removed it) and the zod mirror's
  `.passthrough()`. Declared as `string` on both faces, a **non-string**
  `wrapperClass` that used to parse green is now refused by name — on `SelectSchema`
  and through `safeValidateSchema` alike. Pass the Tailwind class string; a number or
  an object gets a parse error where it used to get silence.
</Callout>
