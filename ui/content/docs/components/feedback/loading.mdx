## Schema

```ts
interface LoadingSchema {
  type: 'loading';
  label?: string;                 // Text drawn under the spinner
  size?: 'sm' | 'md' | 'lg';
  className?: string;
}
```

<Callout type="warn">
  The message under the spinner is `label`, the key `LoadingSchema` declares.
  Until objectui#11347 the renderer read an undeclared `text` instead and left
  `label` inert. `text` is not a key of this node: write `label`.
</Callout>
