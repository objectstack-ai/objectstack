## Usage

Customize e-commerce blocks for your store:

### Add Product Data

A `card` fetches nothing. Records come from a data-bound block that names its
object in the per-element `dataSource` binding (see the
[Data Source guide](/docs/guide/data-source)):

```json
{
  "type": "object-grid",
  "dataSource": { "object": "product", "limit": 20 }
}
```

### Add to Cart Action

A control that runs something is its own node type, `action:button`, and its
props go in the `properties` bag; `actionType: "api"` sends the request to
`target`:

```json
{
  "type": "action:button",
  "properties": {
    "label": "Add to Cart",
    "actionType": "api",
    "target": "/api/cart",
    "method": "POST"
  }
}
```

### Customize Pricing Display

```json
{
  "type": "text",
  "content": "$299.99",
  "className": "text-2xl font-bold text-primary"
}
```
