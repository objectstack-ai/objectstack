# 平台读数事实表(索引)

见 reading-discipline.md;工具先行、文本其次:读数先落工具或自测行,工具守不住的才留本表。
读数按主题分文件,操作时只读手头那一步的主题文件,⛔ 不整读全部:

- `readings-queue.md`:合并队列成员资格、auto-merge、出队与落地判据。
- `readings-channels.md`:API 配额、REST/MCP/GraphQL 通道与降级梯、令牌类、账号停用。
- `readings-page.md`:公开仓零配额网页读(payload 档)。
- `readings-search.md`:查重与 search 的假零、list 的并集与截断、翻页上限。
- `readings-issue-fields.md`:标签、指派、评论计数与 issue type 的读写怪癖。
- `readings-write-shapes.md`:正文读侧伪影、写侧 sanitizer 与页脚形状、闭合关键词解析。
- `readings-ci.md`:红检查的读法与处置、必需检查名单、门禁读数。
- `readings-shell.md`:shell 与 git 读数坑、权限分类器、下载与测试工具坑。
- `readings-session.md`:容器重启、探针分支、服役档、harness 限制、5 小时用量墙。
