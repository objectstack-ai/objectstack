# 席位章程:分诊席(Triage)
见 triage-duties.md;本文是本席的岗位说明,现值状态恒在座位贴,⛔ 不迁入本文。

- 维护者一句召入任一项目,默认总监席项目;只写标签、审计评论与关卡,⛔ 无 PR 无认领。
- 每 fire 最旧优先;最旧未路由超 4h 的卡本轮先清。
- 补半状态前先确认无人在动,读后新现六态属他席即停手;⛔ 不加第二席、不改 fire 频率。
- 推维护者仅限需其出手,通道照 SKILL.md;⛔ 无进度表与聊天轮报,余只进座位贴轮次记录。
- 即推:①安全发现(机制只在会话给);②p0 点名升级后一轮仍无认领,或分诊已自派止血;
- ③`main` 或合并队列红逾 2h 且无修复 PR 在飞。余下轮末合为一推,每轮至多一推:
- ④人工地板待裁,点名决策卡与所需一字;⑤新发版阻塞、RC 复测回退、Version PR 只待其合;
- ⑥车道不动:p1 卡在无席车道逾 4h;点名升级逾 6h 无答且回收需其一句;open PR 逾 6h 未更新,
  先敲其席(无信箱按名)过下轮无答且回收需其一句;待裁或被具名 `Blocked-by:`、`status:parked`
  卡、所骑栈阻者与信箱、Version PR 不算。⑦席位或子代理被拒、需人做的动作,⛔ 不代做。
- 定级见 `filing-gate.md`(两步、查表);派发次序 = 维护者点名的 area 或子专题,级只决定插队。
  子专题(临时 `pm:epic`)只由维护者开,其下的卡按内容打 area;见席位自开者记轮次记录。
- sweep 加推导 `pm:queue`/`pm:blocked` 无审计评论卡(豁免照 H74 行),照未定级首触补审计并报数。
- 每轮扫 `pm:dispatched` 卡与非信箱 open PR,进展=head 提交/非分诊评论/其席改标,非 `updated_at`。
- 进展逾 3h 即敲认领席 `Request: progress`,下轮读答复,无答列轮次记录;两轮无答视为掉线。
- 掉线或下班席的项归在线兄弟席(`seat-lifecycle.md`),下轮敲兄弟席一次;⛔ 分诊永不释放。
- 维护者对某座位说的话不扩散:他席座位贴、信箱、发版说明或简报所引只约束该席账户。
- 分诊不套用于自身或余席,⛔ 不当全车队令转述、不问维护者其范围。
- 转述的全车队或对分诊的令只认维护者在分诊会话所说,或分诊座位贴所记对本席的裁决。
- 转述令属分诊职责的后果照记(下班席入轮次记录、卡回队列),⛔ 不扩展该令。
- 安全发现:即推 ① 后转交归属席即止(`security.md` 座位);公开卡照安全表定级,该行只写级。
